# Cross-game import is universal, and it never folds

Importing a song into the other game was asymmetric by construction: Genshin accepted Sky songs — new-format files through `toOtherGame`'s similarity swap, legacy files through the frozen historic remap — while Sky rejected everything foreign at the door (`SongService.parseSong`: "it's not a Sky song"). The asymmetry predates the universal format; under absolute Note Numbers (ADR-0007) a song's notes mean the same thing in every game, the similarity map (`instrumentSimilarity.ts`) already carries both directions and is built to take a game #3 as a column, and the legacy deserializers already accept an `importInto` target. The gate was the last place that treated the format as game-owned. And the conversion that did run changed the music: `toOtherGame` folded out-of-range Note Numbers into the mapped instrument's range in sounding space, merging fold collisions — so a converted song could play different octaves, and fewer notes, than the file it came from.

We decided (2026-08-23): **any song imports into any game, dispatched game-agnostically, and conversion never rewrites a note.** `parseSong`'s rule is "the song's game is not the running game → convert", with no per-game branches — adding a game means config (a similarity column, legacy tables if it has a legacy), not dispatch code. New-format conversion is the similarity swap alone: tracks move to the target's Similar Instruments, Note Numbers pass through untouched. A number the matched instrument cannot voice becomes a Stranded Note — skipped at playback, visible in the composer, never silently rewritten — exactly what a same-game instrument swap already produces. When a just-converted import contains stranded notes, the user is warned once per import ("some notes might not play…"); a folding tool in the composer can later offer to pull stranded notes into range as an explicit, undoable edit, which is the right home for a lossy operation the import used to apply silently.

Key choices within that:

- **As-is over folded, deliberately.** The fold guaranteed every note sounds, at the cost of octave error and fold-collision merges the user never asked for — and it baked that loss into the stored song, unrecoverable after a save. As-is preserves the song's identity: what plays is exactly what fit, what didn't is marked and kept, and fidelity is recoverable the moment a better-matched instrument (or the folding tool) comes along. This also removes the one place where composed/recorded conversion disagreed with VSRG's, whose cross-game path never rewrote numbers (a preserved QUIRK) — the no-rewrite rule is now uniform.
- **Legacy converts in every direction too.** The frozen-table path (`deserialize(importInto)`) already parameterizes its target; Genshin-legacy → Sky runs the same machinery Sky-legacy → Genshin always did, through the target's frozen tables. Legacy files are the one place remapping remains, because their wire format speaks a game's button indices and cannot pass through as-is.
- **The warning keys on Stranded Notes, once per import.** Folding no longer exists, so "some notes might not play" is precisely the stranded count being nonzero on the converted result. Aggregated per import operation, not per track or per song — a bulk restore of a foreign backup must not toast per song.

Considered and rejected: **keeping the fold behind the warning** — the warning then describes a song the import already altered, and the alteration is unrecoverable; **direction-specific gates** ("Sky accepts only Sky") — nothing in the format justifies them anymore, and each new game would multiply the branches; **erroring on legacy foreign files only** — the machinery to convert them exists and is target-parameterized, so the error would preserve an accident, not a boundary.

Consequences: the "not a Sky song" error and the `APP_NAME` branches in `parseSong` go away, replaced by the one mismatch rule. `toOtherGame` on ComposedSong/RecordedSong loses `foldNumberIntoRange` and the fold-collision merge; its docstrings and the spec's §6 description are corrected. Sky → Genshin imports change behavior: previously folded notes now import as-is and may strand (warned), which is the point of the decision applied to the direction that already worked. CONTEXT.md's Stranded Note entry drops its octave-fold clause. Backup restores of foreign songs convert instead of failing, under the same aggregated warning.
