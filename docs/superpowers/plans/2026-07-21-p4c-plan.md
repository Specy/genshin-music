**Goal:** Land the third and final Phase-4 wave — the three canvas/editor pages that spec §10 calls "roughly half the total effort": **composer** (old `composer/index.tsx` 991 lines + a 16-file `Composer/` tree + `Composer.css` 883), **vsrg-composer** (707 + a 15-file tree + `VsrgComposer.css` 270), **vsrg-player** (233 + a 15-file tree + 6 CSS modules) — as real Svelte pages replacing their `PageStub`s. Everything they depend on lands with them: `pixi.js` as a RAW dependency (no `@pixi/react`), three plain-TS renderer classes (spec §6.2), the three texture caches (`ComposerCache` / `VsrgComposerCache` / `VsgPlayerCache`), `MidiParser` (+ the `@spotify/basic-pitch` audio→MIDI path), `InstrumentControls`, the composer keyboard / tools / breakpoints / timeline, the `VsrgComposerStore` event-emitter and `VsrgPlayerStore` runes stores, `ThrottledEventLoop`, the **AppLink leave-guard** (spec §4.4's guarded-navigation contract, reimplemented on SvelteKit `beforeNavigate`), the **SvgNote per-instrument tint restoration** (the one substantive parity gap left on the branch), and the **Composer half of the theme-page live preview**.

**Architecture:** Same conversion discipline as 4a/4b. Old React blobs (`git show migration/next16-react19:<path>`) are the behavior specs; DOM/class parity so the ported CSS applies. The three `@pixi/react` `<Application>` trees are **rewritten as plain-TS renderer classes** — each owns `Application` init, manual resize, texture caches, native pointer/wheel wiring and an explicit `update(state)`; the `.svelte` component owns lifecycle only (`onMount` constructs with the container element, `$effect` pushes reactive inputs into `update()`, `onDestroy`/returned cleanup destroys). Every `<pixiContainer>` / `<pixiSprite>` / `<pixiGraphics>` JSX node becomes an explicit `new Container()` / `new Sprite()` / `new Graphics()` with the same properties in the same z-order; `$lib/utils/pixiExtend.ts` is `@pixi/react`-only and is **NOT ported**. React class components (Composer, VsrgComposer, VsrgPlayer) become `.svelte` files whose fields become `$state`/`$derived` and whose `componentDidMount`/`componentWillUnmount` become `onMount` + returned cleanup. `mobx.observe`-based subscriptions (`subscribeTheme`, `subscribeCurrentVsrgSong`, `subscribeVsrgScore`, `subscribeVsrgLatestScore`) become explicit `$effect.root`-built `subscribe(cb)` helpers, per spec §6.1.

**Tech Stack:** TWO new npm deps this wave: `pixi.js` (old `^8.19.0`, RAW — `@pixi/react` is explicitly NOT installed, spec §6.2) and `@spotify/basic-pitch` (old `^1.0.1`, the audio/video→MIDI path in `MidiParser`; its model asset `static/assets/audio-midi-model.json` is already in the tree). `is-mobile` and `@tonejs/midi` are already present.
