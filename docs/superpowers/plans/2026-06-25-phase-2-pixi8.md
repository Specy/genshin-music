# Phase 2 — pixi-react 8 + pixi.js 8 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax. NOTE: this project has **no test suite by design** — the per-task verification cycle is **edit → `npx tsc --noEmit` → (build where noted) → commit**, NOT TDD. Do not write tests.

**Goal:** Migrate the 3 pixi canvases + 3 texture-cache classes + ~11 renderer components from `@pixi/react` v7 / `pixi.js` v7 (+`@pixi/graphics-smooth`) to `@pixi/react` v8 / `pixi.js` v8, restoring a fully green typecheck and build (both Sky and Genshin targets), still on the Pages Router.

**Architecture:** pixi.js v8 is a single ESM package with a rewritten Graphics API (build-shape-then-`fill()`/`stroke()`), async `Application.init`, and string scale-modes. pixi-react v8 replaces `<Stage>` with `<Application>` and `PixiComponent`/intrinsics with `extend()` + lowercase `<pixiContainer>`/`<pixiGraphics>`/`<pixiSprite>`/`<pixiText>`. The 3 canvases are **class components** that today read `stageRef.current.app` synchronously to build texture caches; under v8 the app is only available after async init, so cache generation is re-driven from the `<Application onInit={app=>…}>` callback.

**Tech Stack:** `@pixi/react` ^8, `pixi.js` ^8 (drop `@pixi/graphics-smooth`), React 19, Next 16 (Pages Router, static export, `next build --webpack`).

## Global Constraints

> Every task inherits these.

- **Verification = `tsc --noEmit` + build only.** No tests. The pixi files are where ALL current type errors live; the goal is to drive `tsc --noEmit` to **zero errors** by the end and remove the temporary `typescript.ignoreBuildErrors` (Task: final).
- **`tsc --noEmit` is the exhaustive completeness gate for the Graphics rewrite:** v7 methods (`beginFill`, `drawRect`, `lineStyle`, `endFill`, `drawCircle`, `drawRoundedRect`) do not exist on a v8 `Graphics`, so every un-migrated call site is a type error. A cache/renderer file is "done" only when it has zero `tsc` errors.
- **pixi stays client-only.** KEEP the existing `dynamic(() => import(...), { ssr:false })` wrappers in `src/pages/{composer,vsrg-composer,vsrg-player}/index.tsx` (pixi touches WebGL; it must not run during the static-export prerender). Do NOT remove them. They are correct, not a Phase-1 hack.
- **Replace anti-aliasing:** `@pixi/graphics-smooth`/`SmoothGraphics` is dropped (not v8-compatible). Use core `Graphics` and enable `antialias: true` on each `<Application>`.
- **Keep behavior + visuals equivalent.** Minor AA differences are acceptable; geometry/positions/colors must match.
- **Build:** `node ./scripts/buildApp.js Sky` and `… Genshin` (uses `next build --webpack`). Output dirs `build/{skyMusic,genshinMusic}` unchanged.
- **`--legacy-peer-deps` is no longer required** once `@pixi/react` v8 (which peer-deps React 19) replaces v7. Install pixi v8 first; afterwards normal `npm install` should resolve. (If a different package still forces a peer conflict, fall back to `--legacy-peer-deps` and note it.)

## v7 → v8 API mapping reference (authoritative for all tasks)

**Graphics drawing (pixi.js v8) — build shape, THEN fill/stroke:**

| v7                                                    | v8                                                                                                                                              |
| ----------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `g.beginFill(color, alpha)` … `g.endFill()`           | build shape, then `g.fill({ color, alpha })` (no `endFill`)                                                                                     |
| `g.lineStyle(width, color, alpha)`                    | `g.setStrokeStyle({ width, color, alpha })` before the shape, then `g.stroke()` after — OR build shape then `g.stroke({ width, color, alpha })` |
| `g.drawRect(x,y,w,h)`                                 | `g.rect(x,y,w,h)`                                                                                                                               |
| `g.drawRoundedRect(x,y,w,h,r)`                        | `g.roundRect(x,y,w,h,r)`                                                                                                                        |
| `g.drawCircle(x,y,r)`                                 | `g.circle(x,y,r)`                                                                                                                               |
| `g.moveTo` / `g.lineTo`                               | unchanged                                                                                                                                       |
| `g.clear()`                                           | unchanged                                                                                                                                       |
| `new SmoothGraphics()` (from `@pixi/graphics-smooth`) | `new Graphics()` (from `pixi.js`); enable `antialias` on the Application                                                                        |
| `settings.LINE_SCALE_MODE = LINE_SCALE_MODE.NORMAL`   | remove (no equivalent; `settings` is gone)                                                                                                      |

Order rule: in v8 a fill/stroke applies to the shape(s) drawn before it. Pattern: `g.clear(); g.rect(...); g.fill(color); g.circle(...); g.fill(c2).stroke({width,color})`.

**Textures / renderer:**

| v7                                                                                                   | v8                                                                                                                                  |
| ---------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `app.renderer.generateTexture(displayObject, { resolution, scaleMode: SCALE_MODES.LINEAR, region })` | `app.renderer.generateTexture({ target: displayObject, resolution, frame: region, textureSourceOptions: { scaleMode: 'linear' } })` |
| `SCALE_MODES.LINEAR` / `.NEAREST`                                                                    | string `'linear'` / `'nearest'`                                                                                                     |
| `Rectangle`                                                                                          | unchanged (import from `pixi.js`)                                                                                                   |
| `Texture`, `texture.destroy(true)`                                                                   | `Texture` unchanged; `destroy(true)` still valid (no more `BaseTexture`)                                                            |
| `TextStyle({ fontFamily, fontSize, fill })`                                                          | unchanged shape; import from `pixi.js`                                                                                              |
| `FederatedPointerEvent`, `.globalX/.globalY/.target/.button`                                         | unchanged                                                                                                                           |

**pixi-react v8 components/hooks:**

| v7                                                                                           | v8                                                                                                                                                                                                                                                                       |
| -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `import { Stage, Container, Graphics, Sprite, Text } from '@pixi/react'`                     | `import { Application, extend, useApplication } from '@pixi/react'` + `import { Container, Graphics, Sprite, Text } from 'pixi.js'` then `extend({ Container, Graphics, Sprite, Text })`                                                                                 |
| `<Container>` `<Sprite>` `<Graphics>` `<Text>`                                               | `<pixiContainer>` `<pixiSprite>` `<pixiGraphics>` `<pixiText>`                                                                                                                                                                                                           |
| `<Graphics draw={g => { g.clear(); g.beginFill('blue'); g.drawCircle(...); g.endFill() }}/>` | `<pixiGraphics draw={g => { g.clear(); g.circle(...); g.fill('blue') }}/>`                                                                                                                                                                                               |
| `<Stage ref options={{…}} raf={false} onMount renderOnComponentChange>`                      | `<Application onInit={app=>…} autoStart={false} {...appOptions}>` (see canvas tasks). `options` props (`backgroundAlpha`, `autoDensity`, `resolution`, `backgroundColor`) become direct props on `<Application>`; add `antialias`. `renderOnComponentChange` is removed. |
| `stageRef.current.app`                                                                       | the `app` delivered to `onInit={(app)=>…}` (store on the instance); or `useApplication()` in a child component                                                                                                                                                           |
| `stageRef.current._canvas` (native canvas)                                                   | `app.canvas`                                                                                                                                                                                                                                                             |
| `app.renderer.background.color`                                                              | unchanged (`app.renderer.background.color`)                                                                                                                                                                                                                              |

> The exact `<Application>` prop for the app callback (`onInit`) and for disabling RAF (`autoStart={false}`) must be verified against the INSTALLED `@pixi/react` v8 types in the first task; if `onInit` is absent, use the child-bridge fallback documented in Task "Canvas migration pattern".

- For EVERY `app.renderer.generateTexture(g, { resolution, scaleMode: SCALE_MODES.LINEAR, region })` → `app.renderer.generateTexture({ target: g, resolution, frame: region, textureSourceOptions: { scaleMode: 'linear' } })`. Worked example (one representative block — apply the same transformation to all call sites):

```ts
// v7

g.beginFill(color);
g.drawRect(0, 0, w, h);
g.lineStyle(borderWidth, 0x333333);
g.moveTo(0, 0);
g.lineTo(0, h);

  resolution,
  scaleMode: SCALE_MODES.LINEAR,
  region: new Rectangle(0, 0, w, h),

// v8

g.rect(0, 0, w, h).fill(color);
g.moveTo(0, 0);
g.lineTo(0, h).stroke({ width: borderWidth, color: 0x333333 });
const tex = app.renderer.generateTexture({
  target: g,
  resolution,
  frame: new Rectangle(0, 0, w, h),
  textureSourceOptions: { scaleMode: 'linear' },
});
```

### Task 5: Canvas migration pattern + migrate `VsrgPlayerCanvas.tsx`

This task establishes the canvas-migration pattern (Stage→Application, async app via `onInit`) and applies it to the simplest of the three canvases. Tasks 6–7 reuse the pattern.
